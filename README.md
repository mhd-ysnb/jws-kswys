# heihe-chat-bot · 黑盒语音群聊机器人

借你电脑上**已经登录**的黑盒语音客户端（HeyboxChat），在群聊/私聊里以你的账号说话；
每句回复都由大模型现场生成。人设、群记忆、群友档案、表情包收藏整组跟着「人物卡片」走。

> 这个仓库是**空白版**：没有人设卡、没有记忆、没有任何密钥。
> 所有运行数据都在本机生成，`.gitignore` 已把它们挡在 git 外面。

## 它有什么

- **接管客户端**：CDP 连上 HeyboxChat 页面，读消息 / 发话 / 发表情包 / 传图
- **人物卡片**：人设、日记、群友档案、好感、表情包收藏整组跟着卡片切换；
  「本体模式」下角色自己写自己（`self.json`：我确认过的 / 我猜的 / 我还不确定的）
- **agent 模式**：独立会话 + 一组工具（翻聊天记录 / 看日记 / 查知识库 / 联网搜索 / 写笔记），轮数可调
- **语感闸门**：发话前自查（助手腔开头 / 与自己近 30 条的重叠率），撞了就换温度重写
- **心情系统**：基线 + 事件起伏 + 半衰期，影响说话口气
- **主动开口**：冷场冒泡、私聊主动、群聊主动，各有冷却、每日上限、时段
- **知识库**：本地 markdown，白名单式勾选，谁都能挂自己的设定集
- **控制面板**：本地网页（127.0.0.1:8765）或窗口版（pywebview + 托盘），改人设、翻记忆、看消息流

## 快速开始

```text
1. 装依赖        pip install websocket-client pywebview pystray pillow
2. 复制配置      config.example.json → config.json，填 ai.token（DeepSeek）
                 想让会联网搜索，再填 ai.searchKey（博查）
3. 开客户端      双击 黑盒客户端.bat（或自己开着客户端，把路径填进 config.client.exe）
4. 起机器人      双击 启动群聊机器人.bat
5. 开面板        双击 启动面板(窗口版).bat，或 启动监听网页.bat（浏览器版）
```

触发方式默认「被 @ 才接」，面板里可以改成 每条都接 / 前缀 / 关键词。

## 数据都在哪（都在本机）

- `config.json`：你的 Key 和设置——**在 .gitignore 里，永远不进 git**
- `memory.json`：当前人格的实时记忆（聊天记录、群友档案、日记）
- `cards.json`：人物卡片库；`self.json`：本体
- `log/`：运行日志；`kb/`：你挂的知识库

## 目录

```
bot.py          机器人本体：轮询、判断、说话、记忆、心情
monitor.py      控制面板（本地网页）：卡片 / 档案 / 表情 / 知识库 / 设置
desktop.py      面板窗口版：pywebview 壳 + 托盘 + 单实例
app.py          PyInstaller 打包入口（build.spec）
stop.py         停止脚本：先让机器人写完日记再退
黑盒客户端.bat / 启动群聊机器人.bat / 启动监听网页.bat / 启动面板(窗口版).bat / 停止机器人.bat
```

## 已知边界

- 客户端升级后，页面里的 webpack 模块号要重新探测（`bot.py` 顶部 `MOD_*`）
- 一个客户端同一时间只该有一个程序在连；两边都连会打架
- 知识库、卡片、记忆全部只存本机；上传到哪、挂什么库，都是你自己的选择
